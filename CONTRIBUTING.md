# Contributing

This is a personal learning project, but contributions, suggestions, and feedback are always welcome!

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/your-feature`)
3. **Make your changes**
4. **Commit with clear messages** (`git commit -m "Add: description of changes"`)
5. **Push to your fork** (`git push origin feature/your-feature`)
6. **Open a Pull Request**

## Guidelines

- Keep code clean and well-documented
- Follow PEP 8 for Python code
- Add tests for new features
- Update README if adding new projects
- Write clear commit messages

## Feedback & Discussion

- Open an issue for bugs or suggestions
- Start discussions for ideas and improvements
- Share your own AI automation experiences
